# Campus Lost & Found

A simple web application that helps students manage lost and found items on campus. Users can submit information about an item, view submitted items, filter items by **Lost** or **Found**, and delete entries.

The project uses the browser's **Local Storage**, allowing submitted items to remain available after refreshing the page on the same browser.

## Features

- Add a lost or found item
- Enter:
  - Item name
  - Item description
  - Item type
  - Location
- Display submitted items as cards
- Filter items by:
  - All
  - Lost
  - Found
- Delete an item
- Form validation to prevent empty submissions
- Data persistence using browser Local Storage
- Responsive layout
- Hover effects and status tags

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
